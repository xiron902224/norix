# Dashboard overview

After login you land on **Overview**. The left sidebar is the primary map of the product.

| Nav item | What it is for |
|---|---|
| **Overview** | Fleet pulse: projects, nodes online, recent activity |
| **Projects** | Apps you own — create projects and workloads |
| **Deployments** (Ops) | Backups, alerts, deployment-oriented ops views |
| **Databases** | Managed database instances |
| **Domains** | Hostnames, routes, TLS |
| **Regions & nodes** | Agents, join tokens, cordon/drain, **Update agent** |
| **Runtimes** | Wasm / alternate runtimes |
| **Networks** | Overlay / network status |
| **Sandboxes** | Ephemeral environments |
| **Previews** | PR preview deployments |
| **Observability** | Metrics / signals |
| **Access / Settings** | Teams, members, SSO-related settings |

The top bar shows your user and organization context. The version under the logo is the **control plane** version (`GET /status`), not each agent’s version (agents are listed under Nodes).
